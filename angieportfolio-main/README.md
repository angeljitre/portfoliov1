# Portafolio de Angélica Jiménez — v23

Portafolio React/Tailwind con Spline, modos oscuro y claro, ES/EN, galerías,
videos y formulario de contacto. Todos los recursos utilizados por la página
están dentro del proyecto.

## Primera instalación

```bat
cd frontend
npm install
```

El archivo `.npmrc` ya activa la compatibilidad necesaria con peer dependencies
y utiliza el registro público de npm.

## Desarrollo

```bat
npm start
```

Abre `http://localhost:3000`.

Al terminar, detén el servidor con `Ctrl + C` y confirma con `Y`.

## Vista de producción

La carpeta `frontend/build` ya está incluida:

```bat
npm run preview
```

Abre `http://localhost:4173`.

Después de modificar el código:

```bat
npm run build
npm run preview
```
