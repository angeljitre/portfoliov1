# Frontend — Portafolio v23

## Instalar

```bat
npm install
```

## Desarrollo con recarga automática

```bat
npm start
```

Abre `http://localhost:3000`.

## Compilar producción

```bat
npm run build
```

## Revisar producción localmente

```bat
npm run preview
```

Abre `http://localhost:4173`.

`npm start` consume más memoria y CPU porque mantiene el compilador y la
recarga automática activos. Para evaluar el rendimiento del enlace publicado,
usa `npm run preview`.
